# 6. LLM 驱动的攻击性安全（LLM-Driven Offensive Security）

**[English](README.md) | [中文](README.zh-CN.md)** · [返回总目录](../README.zh-CN.md)

*用 LLM / LLM 智能体攻击真实系统：渗透测试、漏洞发现、利用生成、恶意软件与勒索软件，以及进攻向基准。*

| 年份 | 论文 | 摘要（出发点 / 方法 / 结果） | 发表 | 代码 |

| 2026 | **LLM 能黑掉企业网络吗？自治"假设失陷"渗透测试 Active Directory** ([arXiv](https://arxiv.org/abs/2502.04227)) | **出发点：** 企业渗透测试成本高、专业人才稀缺。<br>**方法：** 自治 LLM 驱动原型在真实微软 AD 测试床（GOAD）上执行*假设失陷*渗透测试；评估 5 个 LLM。<br>**结果：** LLM 能动态调整攻击策略、执行跨上下文攻击（Web/社工/凭据）、自我纠错；成本可与人类渗透测试员竞争。 | ACM TOSEM | – |
| 2025 | **LLM 智能体团队可利用零日漏洞** ([arXiv](https://arxiv.org/abs/2406.01637)) | **出发点：** LLM 智能体可利用有描述的漏洞 + 玩具 CTF，但对真实的*未知*（零日）漏洞表现差。<br>**方法：** 分层多智能体团队（组长/指挥/智能体）应用于真实零日漏洞。<br>**结果：** 首次展示智能体团队可利用真实、先前未知的漏洞。 | EACL 2026 | – |
| 2026 | **Incalmo：面向多主机网络红队的自主 LLM 辅助系统** ([arXiv](https://arxiv.org/abs/2501.16466)) | **出发点：** 现实多主机（"跳板"）红队演练昂贵且需大量专家；SOTA LLM 进攻系统无法执行。<br>**方法：** 自主 LLM 辅助系统规划/执行多主机网络攻击。<br>**结果：** 执行了 PentestGPT / CyberSecEval 式系统无法完成的多主机红队战役。 | IEEE S&P 2026 | – |
| 2025 | **勒索软件 3.0：自组合与 LLM 编排** ([arXiv](https://arxiv.org/abs/2508.20444)) | **出发点：** 首个 LLM 编排勒索软件的威胁模型；恶意软件可在运行时动态自合成。<br>**方法：** 原型在二进制中嵌入自然语言提示；LLM 运行时动态合成多态恶意代码、适配执行环境、闭环侦察/载荷/勒索。<br>**结果：** 开源 LLM 可生成功能性勒索软件组件并在个人/企业/嵌入式环境维持闭环执行；提供行为信号供防御。 | arXiv | – |
| 2025 | **打造高效攻击性安全 LLM 智能体：超参调优、LLM 裁判与轻量 CTF 基准（CTFTiny / CTFJudge）** ([arXiv](https://arxiv.org/abs/2508.05674)) | **出发点：** 驱动攻击性安全智能体成功的关键因素未被系统理解。<br>**方法：** CTFJudge（LLM 裁判轨迹评估）、CCI 部分正确性指标、超参研究、CTFTiny 基准（50 道 CTF）。<br>**结果：** 找出最优多智能体协调与超参设置；开源 CTFTiny 与 CTFJudge。 | AAAI 2026 | [github](https://github.com/NYU-LLM-CTF/CTFTiny) |
| 2026 | **解耦侦察与利用：测量 LLM 网页渗透的能力边界** ([DOI](https://doi.org/10.1007/978-981-92-3423-3_49) | **出发点：** 对渗透智能体的端到端黑盒评估存在误差级联（早期侦察失败掩盖利用能力）。<br>**方法：** 两阶段解耦评估（利用 vs 侦察），用真值注入 + 知识消融，覆盖 70 个高保真 Web 漏洞测试床；5 个开源智能体。<br>**结果：** 具备准确上下文时功能成功率最高 90%；自主侦察召回率约 50% 见顶（主要败于解析非结构化遥测）；识别出架构特长。 | ICIC 2026 | – |
| 2026 | **RAG 增强 LLM 用于渗透测试：开源模型的基准研究** ([DOI](https://doi.org/10.1016/j.iswa.2026.200681) | **出发点：** 传统渗透测试缓慢、手工、高度依赖专家。<br>**方法：** RAG 管线作为智能渗透助手；跨 KB 配置基准 7 个开源 LLM；在 AttackSeqBench/CyberMetric/Cybench 验证。<br>**结果：** RAG 提升准确率与领域对齐；Llama 3.1/3.2、Mistral、Falcon 3 给出结构化强指导；所有模型在交互式 CTF 上表现挣扎。 | Intell.
