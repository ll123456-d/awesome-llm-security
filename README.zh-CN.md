# Awesome LLM Security（LLM 安全文献精选）

**[English](README.md) | [中文](README.zh-CN.md)**

本仓库整理了一组关于 **LLM 安全与防护** 的前沿论文，涵盖六大主题：白盒/机制可解释安全分析、越狱攻击与自动化红队、护栏与安全防御、代码大模型安全、智能体与多智能体安全、以及 LLM 驱动的攻击性安全研究。

> 论文源自一组 Zotero 阅读清单。**每个主题一个文件夹**，内含 `Year | Paper | Summary | Venue | Code` 论文表格（正文摘要为英文，本页为中文导航）。已对原始（重叠的）多个分类进行去重，每篇论文只归入最相关的一个主题。

## 📖 阅读格式说明

每篇论文的摘要（英文）遵循统一结构：
- **Gap**（出发点/局限）：该工作要解决什么问题
- **Method**（方法）：核心思路 / 技术 / 所用知识
- **Result**（结果）：主要发现与量化指标

来源标注为会议 / 期刊 / arXiv 预印本（已知时附 arXiv 链接）。
